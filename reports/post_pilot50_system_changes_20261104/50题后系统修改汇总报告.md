# 50题实验后系统修改汇总报告

日期：2026年11月4日。范围：50题结果报告之后的六组代码修改与零API验收。

## 总体结论

本轮主要修复了证据积累、关联接收、交付观测和候选准入边界。已有代码和模拟测试证据，但没有重新运行真实长期学习实验，不能声称已经提高数学正确率或实现跨原题收益。原50题结果、UNKNOWN、费用预留及拒绝记录保持原状。

## 修改清单

| 修改 | 原问题 | 当前实现 | 验收与局限 |
|---|---|---|---|
| 1. 关联生命周期 | 请求结束即将证据排除，空簇或拒绝后旧失败难以重访 | 分离NEW、ATTEMPTED、RETRY_ELIGIBLE、LINKED、EXHAUSTED；独立关联尝试账本；每证据当前版本最多3次，需新证据触发重访 | 零API覆盖空簇、拒绝、耗尽、时间隔离；LINKED只是接收关系，不表示机制成立 |
| 2. 无簇证据检索 | 必须已有簇才能带回旧证据，形成启动困境 | 新增确定性Evidence Retrieval；新失败作为锚点，检索不同已知原题的旧未关联证据；保留候选、排序理由及预算审计 | 不依赖已有簇；来源未知不冒充独立；检索共同出现不代表共同根因 |
| 3. 输入输出Schema边界 | 输入verified:false被复制到输出，触发严格拒绝 | 分离ClusterContext、ClusterProposal及宿主VerifiedCluster；上下文不暴露权限字段；输出嵌套权限字段均拒绝 | 历史39份原样仍拒绝；仅在诊断副本移除verified:false后38份通过，1份仍因引用未提供簇而拒绝；不是新实验成功率 |
| 4. 事件、引句与关系 | 同一事件多引句被重复evidence_id拒绝 | 每簇每事件一个聚合关系，支持1—8条引句；四类关系；重复关系给出字段诊断，最多一次有预算的新修订请求 | 不静默合并或删去矛盾；修订必须保留证据、引句和机制判断；目前真实修订仅用模拟响应验收 |
| 5. 源码交付观测 | 本地契约失败把供应商stop覆盖成error | 新增不可变DeliveryObservation；分开供应商事实、契约、程序、数学和登记状态；明确列出缺字段 | 历史8982字符源码AST通过，外层字段仍缺失，因此拒绝登记；数学正确性未评价 |
| 6. 算子契约与验证绑定 | 参数化源码可能被误当成已证明的复用能力 | 区分INSTANCE_SOLVER与REUSABLE_CANDIDATE；模型契约与宿主阶段记录分离；源码及契约联合绑定；接入已有注册表 | 接收模型不能授予权限；专用程序不能获复用资格；新契约需来源、安全、独立Gate、Shadow观察记录及原有门槛；端到端自动生成与验证记录接入尚未完成 |

## 当前证据如何重新进入学习

可信失败永久保留 → 计算关联状态 → 新失败到来 → 无需已有簇即可检索旧证据 → 受条数和字节上限约束组包 → 模型提出关系与双判断 → 严格检查来源、引句、字段及关系 → 接收为未验证机制，或保留拒绝与新证据重访机会。

无新证据不自动循环调用。EXHAUSTED表示本策略版本有限尝试用完，不删除原始记录；未来重评需要明确策略版本和预算。最终wire预检及UNKNOWN阻断仍生效。

“失败原因判断”和“算法可生成性判断”此前已经分离，本轮保留该设计：根因SUSPECTED或UNSUPPORTED与算法GENERATE可以同时存在。它们只允许提出可测试候选，不构成算法正确或可复用结论。

## 新候选的准入边界

模型契约包含input_schema、preconditions、output_schema、algorithm、complexity_bound、failure_modes、source_evidence及artifact_kind。验证状态不由模型填写。

新契约记录绑定源码SHA与契约SHA。代码或契约改变，旧记录不能授权新版本。独立Gate需已知且不重叠的原题身份；同题改参数不能冒充独立原题。STATIC_SAFETY、SOURCE、INDEPENDENT_GATE、SHADOW_OBSERVATION各阶段最新记录需通过，且不能替代原有Gate和有限试用条件。

旧制品无新契约时维持旧协议兼容，不能将其表述为通过了新标准。当前record_stage仍是可信宿主接口，尚未全部自动连接实际验证器；手填或Mock通过记录不能构成数学或安全证明。

只读交付回放保留供应商stop与原始响应SHA，确认外层缺applicability、description；源码可AST解析仅为语法证据。未对该候选进行安全执行或数学评分，也未补登记到旧Run。
