# 冻结收益只读评估工具

日期：2026-11-05。交付：独立分析器、固定方法JSON、使用说明和测试。没有修改在线学习器、评分结果、权限、预算或旧contract_metrics占位值；离线结果不会反馈到正在运行的Agent。

## 能力

1. 从冻结逐题锁定与独立评分记录计算F/G、F/T、F/R净正确数及原题等权差。
2. 对实际介入子集给同题工作流配对，不能当作同检查点因果增益；后者缺反事实记录时继续不可评价。
3. 按精确候选版本、授权时序、源码、谱系和曝光记录审计不同原题复用；Mock和缺少谱系不会产生真实独立收益数字。
4. 将误接受、误拒绝、UNKNOWN、ERROR、参数映射和联合接受分开；统计条件于冻结宿主标签，评审身份认证仍是外部依赖。
5. 区分失败证据覆盖到Gate的比例与候选版本到Gate的转换率；无分母时不报0%。
6. 包含基础/额外求解、学习/修订、验证的全部原始响应和Worker账本，费用不与预留混淆；缺报价不推断免费。

## 固定方法

正式实验前冻结方法与分析器SHA。主比较F/G，次要F/T与F/R全报；原题去重、谱系聚类的精确符号检验和缺失敏感性分析固定。旧Run没有绑定这些哈希，本轮只读重放明确为事后工程探索，不能追认为事前注册。
