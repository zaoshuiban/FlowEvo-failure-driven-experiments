## 问题与停止条件

只检验真实 Actor 失败 → Teacher 成功实现 → 参数化操作 → 同 SHA 第二训练来源 → 原 Actor 自主调用的链路。每阶段允许得到零项结果；不扩大任务池，不替换迁移题，不为凑成功补抽候选。本轮不证明稳定成功率提升，也不检验失败选择优于普通选择。

固定一条真实 HumanEval 数据入口；不改 benchmark 标签。数学、ALFWorld 完整扩展、TACO/LCB 适配和正式 G/G+F/G+U 比较留待后续。历史 18 个 development 失败不计入本轮训练。

## 数据与角色

本地原版 HumanEval 164 题中，**68 题**有受支持的非空公开例子（初查 67 的口径是遇到一个不支持例子便舍弃整题；最终转换逐例保守筛选）。只转换 docstring 中单个直接函数调用及字面量预期输出，不执行参考解，不由模型猜答案。

冻结 24 个 train、12 个 transfer_dev，具体 ID、原始 prompt、入口、逐例转换依据、公开哈希、来源及近重复组均见 Pilot_Data_Manifest.json。训练与迁移均属于已存在的开发数据，不声称从未曝光。现有 reserved_eval 和封存 60 局未打开；未使用的 HumanEval 题也不自动称为未曝光正式评价。

人工依据公开描述划分 number_theory、sequence_transformation、string_structure 三个粗粒度候选能力层，并保守合并近重复组。它们是选择用假设，不是已确认根因或已取得的三种算法。具体任务／派生来源／近重复跨角色隔离，能力层可跨角色。未进行独立于公开描述的穷尽语义去重，结论因此只限开发诊断。

原生 loader 新增本地 gzip 和 public_only 投影；Actor/Teacher 只接收公开 prompt、例子、真实允许反馈。原始 test、canonical_solution 均不进入这些 task 对象。公开 import 随任务程序保留，避免类型注解被验证器错误破坏。

## 阶段与原生行为

|阶段|固定职责|
|---|---|
|preflight|真实 loader、角色、公开验证、配置、库路径、Docker 后端与预算检查|
|collect|原生 BenchmarkRunner / Planner / LLMGenerator / Executor；24 题正常最多初稿加2次修复|
|acquire|从可信公开失败按任务 ID 的 SHA 排序，每个能力层最多一个来源，合计最多3项|
|support|同一冻结候选、一个独立训练任务、最多2次教师调用程序尝试|
|freeze|冻结共同基础 G 和 G_plus；G_plus 只增加通过第二支持的操作，不加入教师来源题完整程序|
|transfer|固定12题×2组，真实 Actor 自主决定调用；未准入任何操作则跳过|
|report|漏斗、逐题调用／完整任务成败、增加成功／增加失败、分阶段与逐题成本|

仓库默认库注册文件不存在，本轮显式记录 fresh native study 的空起始库；不是移除已有加载技能。原生成功学习、检索、提示复用、正常修复、规划与回退保留。每题记录初始库哈希，collect 后共同基础库完整复制。治理沿用 RunnerConfig 默认 disabled，不偷偷调用额外治理模型。

新执行标准不足的旧 helper 和普通原生成功 helper 继续原有源码提示复用；不因未取得新契约而终止求解。只有满足同一验证、哈希、契约和准入要求的操作进入冻结模块执行。所有组使用这套共同接口；其影响不能归因为失败学习。

## 获取与第二支持

来源 Teacher 最多初稿＋一次真实反馈修订；只提供公开任务、Actor 实际源码和公开执行反馈，人工不提供核心算法。教师成功独立保存 trace，不改学生成绩。没有可复用操作记 SUCCESS_WITHOUT_REUSABLE_OPERATION；准入拒绝也保留。

每个来源只保留原生提取后按既定顺序得到的一个有完整契约候选。冻结源码 SHA、依赖、契约和入口。第二来源 B 从同能力层的独立 train 中选一个：先比较入口与 helper 参数个数差，再比较契约／公开题目的词汇重叠，最后 SHA 排序。这个规则只使用训练公开信息，是兼容性启发式，不保证适用；B 可成功也可失败。选定后不换 B。

Draft 只能通过带候选 ID 和 SHA 的训练支持入口加载；普通执行不能加载 draft。B 的程序必须完整公开验证通过、运行回执确实调用同 SHA。再将该调用的返回值替换为 None 重放，确认结果对返回值有依赖。该检查是保守诊断，可能漏掉对 None 不敏感的合法复用；源码保留供审查，不能把仅调用后丢弃结果计作支持。支持成功后按独立来源去重进入 active；重导入不加支持，换源码不继承旧支持。

## 比较与评分

G/G_plus 使用相同 Actor、任务、公共执行接口和最多3次解题请求，独立库副本。迁移阶段冻结全部学习；Teacher 不可访问。请求、代码、展示事件、真实开始／返回／异常、参数类型及有界参数预览均保留。前提是否完全符合契约需结合调用源码人工审查，不以运行成功替代前提证明。

全部迁移程序固定后，执行返回值依赖诊断及独立最终评分；私有 test 仅交给本地隔离评分器，不回传 Actor、Teacher 或编译器。不依据任何评分换题或修技能。公开测试局部返回成功、整题最终失败仍计整题失败。主指标是完整任务配对成败和新增成功／新增失败；双成功时调用减少仅是效率信号。原生模型请求和隔离执行成本分别记录；诊断消融和最终评分成本与部署成本分开。

## 隔离与授权

复用 DockerWorker 与已存在不可变 Python 镜像，SHA 见冻结配置。任务文件、监督程序和冻结模块只读挂载；断网、非 root、只读根文件系统、去除 capabilities、256MiB、1 CPU、32 PID、/tmp 32MiB。任务5秒超时，CPU／文件／输出另有限制；模型密钥和宿主数据目录不进入容器。原生验证及准入统一注入同一个隔离 Sandbox，不回落宿主执行。

准入与调用日志是非对抗研究的执行证据，不宣称解决恶意 Python 伪造同进程日志的完整安全问题。后端未启动或执行状态未知按工程异常停止，不伪装能力失败。

授权只需一次，针对上述36个真实任务公开材料、Actor/Teacher模型、180次请求、512次执行、$8、3小时和绝对截止。授权后写入绑定本协议 SHA 的本地授权记录并运行 all；不逐阶段重复询问。
