# ALFWorld B v2 证据投影与隔离审计

| 数据角色 | 代码路径与访问范围 |
| --- | --- |
| 原始学习证据 | 从正式 G 协议、逐局提交链和 RESET/STEP 环境回执读取。核对冻结题序、提交链、动作、步数与 won。B 发送目标、初始观察、历史动作与反馈、动作当时是否合法、锚点前合法动作及真实恢复后缀。 |
| 分析与机制 | 两批分别接收独立分析。原始引句必须逐字匹配步骤，机制仅可引用有恢复引句的非弃权记录。生成只接收选中机制及其引用分析。请求绑定阶段及投影哈希。 |
| 来源验证 | 原始历史恢复后缀只作为宿主验证参考。Worker 接收当前公开目标、观察、合法动作、已走历史及自身有界状态。后续历史、轨迹路径与源游戏身份不进入 Worker。 |
| 事后诊断 | 旧诊断报告、人工分类、手写替代分支、探针及目标位置都未被学习入口打开。 |
| 独立候选池 | 单独命令审计元数据。B 冻结、学习、生成及来源验证入口不接收池参数。没有启动 Gate 游戏。 |

沿用 FailureEvidenceStore、BoundedCompiler、持久账本、FrozenLinuxBackend、EnvironmentPolicyRunner 与 FailureOperatorRegistry。每个 B 阶段有稳定请求身份，共享一个预算和供应商日志。候选编译规格源自已核对的模型归并产物。响应及拒绝保留在阶段日志中，源码或来源版本变化不会沿用旧证据。

静态检查复用现有权限边界，宿主另外从所有 B 来源公开动作识别已见实例字面量并拒绝硬编码。AST 筛查能拦截可辨识的直接字面量，隐蔽专用化仍需独立验证。零 API 中的手写合成夹具只由测试入口注入，真实入口没有夹具注入参数。
