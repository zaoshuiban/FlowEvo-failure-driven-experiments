## 2. 下一轮三组对照

| 组别 | 实验行为 | 能回答的问题 |
| --- | --- | --- |
| S0 现有修订策略 | 冻结当前已运行的 Python 源码 SHA-256，按原路径执行 | 现有来源覆盖及边界误触发水平 |
| S1 学习适用边界 | 使用同一策略作为计算与动作执行基础。只根据预先允许的训练反馈生成适用判断，给一次有界修订。 | 学到的判断能否保留恢复能力并减少误触发 |
| Rule 最小人工规则 | 在同一策略前设置确定性的适用判断，规则在评价前冻结。 | 学到的判断是否在覆盖、误触发和成本上优于简单检查 |

S1 与 Rule 共用公开状态、策略执行与回退路径。将适用判断作为同一入口的前置环节，保留当前合法动作检查及开启之后才复查投递的逻辑。三组用同一检查点、同样动作上限。Rule 的比较范围限于预先定义的通用检查，分别核实当前目标的所需操作及其参数、必要的先行操作是否已有公开回执、显式实例是否相容。缺少可信映射时输出 UNKNOWN。规则方案尚未实现或执行。

三组都先在 11 个来源回归检查保持情况，并分别核算 21 个已曝光边界上的行为。独立评价先在相同公开检查点观察首动作或拒绝，再用独立环境回执确认目标相关的局部修复。拒绝后的回退用相同的冻结原生路径。只有实际在完整环境分支执行且记录终态时才统计整局收益。
