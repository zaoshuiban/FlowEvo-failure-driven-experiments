## 证据契约

每条原始公开步骤带有 `<轨迹证据哈希前12位>:step_NNN`。模型只提交失败步骤 ID 和 1–2 个恢复步骤 ID，也可以弃权。宿主核对轨迹归属、失败锚点、引用存在性、恢复严格晚于失败、引用唯一性，再从锁定回执回填原动作和完整反馈。跨轨迹步骤、未知步骤、锚点之前或当步、重复引用均被拒绝。16 个事件的步骤命名空间在运行前检查无冲突。

逐记录接收。重复提交同一轨迹时该轨迹隔离，其他有效记录继续；缺失、错误归属和无效记录逐条留原因。可解析批次中，部分记录有问题时保留其余记录；无法解析或不完整的批次保留原响应并拒绝该批输入。恢复与预算遇到 UNKNOWN 仍按既有安全规则停止。归并门槛冻结为至少两个不同轨迹的可信非弃权假设；门槛通过后仍允许单例机制。真实分析通过仅表示来源引用成立，机制与修复需另行验证。
