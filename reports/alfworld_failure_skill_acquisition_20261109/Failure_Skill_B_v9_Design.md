# ALFWorld B v9 失败恢复决策一致性实验

本实验测量模型能否从公开记录识别恢复所需事实、能否把已识别事实转化为一致判断，以及显式输出事实是否改善恢复判断。

| 开发证据 | 与本轮设计的关系 |
|---|---|
| B v4 真实响应提出跨容器共同机制 | 同一恢复判断需要覆盖不同容器和上下文 |
| B v5 失败后来源修复 4/4，出现误触发 | 应恢复和应拒绝需要分别测量 |
| B v6 工程修订后来源修复 4/4，负例误触发 7/20 | 旧失败和当前任务可能脱节 |
| B v7 来源修复 0/4，负例误触发 1/20 | 避免误触发可能伴随对正例的过度拒绝 |
| B v8 四条真实来源 A/B 判断全对，B 仍出现 6 个明确错误 YES | 目标识别、时效判断与最终恢复判断需要拆开观察 |

已核对历史冻结协议、结果报告和原始响应。v4 的原始响应包括两批分析和一批归并，正式归并因交付上限被拒。v5–v7 的原始策略各来自一次源码响应。v6 的 4/4 来自单独记录的工程修订版。

D 直接输出失败相关性、同一障碍是否仍存在、恢复决定和证据引用。S 使用相同公开输入，额外输出目标与失败实体、匹配、持有物和任务阶段、障碍解除与后续证据，然后给出相同三项判断。两组各有 6 个独立请求，按同一冻结顺序每批 6 条。D 先执行，S 随后执行。组间无共享模型上下文。两组固定同一模型、温度、JSON 模式和单请求输出上限。S 的指令与字段较多，因此实际输入 Token 与费用按组报告。这个设计比较两种完整判断方式，无法把效果进一步拆成字段数量和提示措辞的单独贡献。

原始模型判断、宿主一致性检查和冻结标签评分分别保存。结构合格的矛盾输出保留原始决定并参与评分。D 与 S 使用相同的基础矛盾规则。S 另外报告中间字段提供的检查机会，两组的总矛盾数分母不同，比较时同时看共同规则及新增规则。检查结果没有执行权限。

主要描述指标为同一记录上的正确 YES、明确错误 YES、应恢复却判 NO、应恢复却弃权、未知时过度 YES、正确 NO 和交付覆盖。固定输出全 36 条、各组已交付以及两组共同交付三个口径。配对转移表记录参考标签、D 决定、S 决定以及缺失，不仅报告同时答对的条目。按来源角色分列，重复上下文保留为诊断记录。样本已曝光且含合成数据，结论限定于开发比较。

S 若能识别事实但决策矛盾，后续应检查前置条件与决策的整合。若事实本身多错，应先审查可见信息和标签定义。真实判断及跨游戏表现仍待验证。
