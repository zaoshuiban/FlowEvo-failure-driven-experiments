新合成覆盖物体类别、容器类别、显式目的地实例冲突、物体冲突、同类多实例、信息不足。采用 plate/cabinet 与 mug/drawer 两套固定组合。它们是人工构造的公开状态夹具，未在真实环境执行，不能算未见游戏泛化。没有根据 v7 输出选择通过样本，也没有输入人工恢复动作。

每条数据有 public、A/B 参考标签、角色、类别、标注依据和来源。真实来源通过原始 episode/environment 回执加载，核对120局完成状态、23条事件与673步的一致性，再截取公开前缀。模型不接触恢复后缀、won/score、专家计划、事后诊断或 Gate。20个回归上下文仅复用公开字段，旧 expected 和旧策略结果均未进入请求。

实例名称由失败动作明确提取，只确定命令所指实体，不自动判定是否适用。匹配与时效标签由宿主按公开证据逐类标注，并记录 basis，不由待测模型或修复策略自评。来源四例有拾取、到达、加工回执等证据。无失败动作的记录，实体与绑定未定义，标 UNKNOWN。显式 safe 3 与 safe 2 冲突为 CONFLICT。后来打开、成功投递、更换持有物分别记录状态变化，不把任何变化都当作恢复。

多实例例的 UNKNOWN 采用保守绑定定义，表示公开信息不能确立唯一当前目的地，并不声称 ALFWorld 的所有类别目标都只允许某一个实例。该假设是本诊断的测量边界。参考标签为开发标注，非外部盲审金标准。

样本 ID 对模型统一为 case_001 等无语义编号，原名称和类别保留在私有审计文件。A/B 请求只有公共白名单字段，不包含参考标签或另一实验的输出。新合成样本在调用前冻结，禁止后续用于完整策略生成 Prompt。冻结后修改标签或 Schema 必须启用新协议。

完整公开状态与逐条依据保留于本机 dataset.private.json。公开报告仅给出哈希，历史 v3–v7 共222个文件已核对未改写。
