# V3自动测试与独立Oracle

模型生成器要求自主提出POSITIVE、NEGATIVE、NEAR_MISS、BOUNDARY、AMBIGUOUS测试，记录原题、变换维度、预期行为和不变量；不要求数值答案。生成结果全部保存，不筛除失败题提高通过率。

IndependentOracle只接受宿主独立审核的题面精确匹配记录：可信参考哈希、语义审查哈希、非待测实现来源。候选solver/matcher哈希不得作为Oracle哈希。模型自报答案和语义不构成授权证据；改写后题面没有独立审查就UNVERIFIED，不能因文本相似复用答案。

这意味着“能自动提出测试”与“已经拥有可信测试”分开统计。当前实现不会用候选计算自己的期望值，也不会将生成器与候选的自洽结果当作正确性。缺少独立依据是合法阻断，不能靠增加模型投票掩盖。

原P3 Design可做DEVELOPMENT_EXPOSED回归。冻结私有参考供评分进程读取；Gold不进入生成请求或Worker。算法单测需要独立确认的参数，不能用match自己输出的参数证明match正确。对未审核参数，只报告联合数值匹配，不声称Computation/Applicability同时通过。

同理，原数据集的“near-miss”标签不是新算子的永久拒绝规则：若新模型声明并实现更广范围，独立审查应检查新范围内计算正确性。若无法确认语义，保留UNVERIFIED而非强制判负。

本轮真实生成数量、Oracle准入漏斗及逐题记录在运行完成后补入最终报告。Mock测试仅证明工程边界。

## 本轮真实漏斗

真实生成测试提案0，可信Oracle验收0，独立语义/答案审核0。原因是包含源码和测试的响应未完成交付，并非测试全部通过或全部失败。未新增独立数学Oracle，也未调用待测算子反推Gold。Mock覆盖完整提案保留、未经审核UNVERIFIED、自举Oracle拒绝及双指标；这些不能代替真实自动测试的效力证据。
