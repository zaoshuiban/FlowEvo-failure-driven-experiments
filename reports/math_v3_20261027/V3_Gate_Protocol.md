# V3独立Gate协议

本轮不将已曝光P3 Design重命名为独立确认。必须在任何Gate结果读取前冻结所有比较版本的联合SHA、任务顺序、Oracle及语义审查记录。

进入条件：独立审核的结构化参数上solve正确；独立确认的适用/不适用题上match及参数正确；联合正确；具有真实正例能力且不只是全部拒绝；没有已知错误/误触发；具备同检查点Generic配对价值证据。仅形式合法和模型自报passed均拒绝。

P0 Gate仍是同一历史定向参数化分布，并不代表不同自然原题谱系。若没有独立语义与答案依据或与Generic配对记录，保持Shadow，不能把默认P0文件名当作独立性证明。

一次Gate按预冻结候选集合执行；新版本不可加入已经曝光的同一Gate。Gate反馈不回流生成器，失败保留Shadow。UNKNOWN请求不重发；算子返回错误数值不能借私有Gold在线回退。

当前尚无符合上述全部要求的v3版本，不能承诺本轮会授予Experimental。此协议是门控要求，不是通过证据。
