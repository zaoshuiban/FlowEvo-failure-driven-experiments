Scope: bounded deterministic repair operator for incomplete-artifact recovery when the current candidate artifact is empty or structurally incomplete. Preconditions: payload provides task_public, candidate_code, public_feedback, candidate_ledger, remaining_budget, hook; a non-empty source program may exist in candidate_ledger or source_programs. Allowed actions: (1) decline when public validation is unavailable/unknown/failed, when no complete non-empty candidate code exists in the ledger or supplied sources, or when the only recoverable artifact is empty; (2) apply by selecting an existing ledger candidate id only if host-verified PUBLIC_PASS is present in public_feedback for that candidate; (3) apply by emitting candidate_code only when a complete non-empty source program is available from supplied material and no unverified pass is claimed. Decline conditions: unknown public validation, NO_COMPLETE_CODE, empty artifact, missing source, or any request to assume historical checks passed. Never fabricate ledger entries, never claim test success, no task-specific hardcoded patches, no external access.
