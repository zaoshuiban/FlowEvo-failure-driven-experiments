# FlowEvo v2.1 设计修订说明

依据S1.1一致性审查，保留v2架构，集中补齐“真实失败→自动规格→可执行源码→设计筛选→独立门控→experimental未来试用→条件收益测量”。本次为设计修改，未修改源码、未调用模型、未执行服务器实验或推送远程。

| 修订 | 具体落点 |
|---|---|
| 校准成熟度 | 基础框架本地验收通过；真实生成主链、目标服务器和在线收益仍待验证 |
| 自动生成作为优先任务 | 在已有LearningLoop/BoundedCompiler职责中编排完整状态链；规格不等于制品；明确幂等、失败和成本记录 |
| 目标服务器前置验收 | 核实真实入口、模型、成功库、提取器和Linux Worker；固定响应验证透明性 |
| 能力范围分期 | S1.2先保持算子无内部模型调用；学习生成调用单列；未来扩展走宿主代理 |
| 公开验证三分类 | passed/failed/unavailable；候选先登记，缺测试不静默丢弃、不作为功能失败、不直接部署 |
| 晋级与对照 | experimental足以进入受控试验；Active不阻塞；共同公开协议及独立成功库状态；F需对照G/M |

本轮已同步更新[设计v2.1](FlowEvo失败驱动系统设计v2.md)与[实验计划v2.1](FlowEvo_E3下一步实验计划.md)，沿用文件名以保持既有链接。设计新增字段和编排要求尚未实现，不沿用旧93项测试作为其通过证明。此前实现报告保留原始结果。
