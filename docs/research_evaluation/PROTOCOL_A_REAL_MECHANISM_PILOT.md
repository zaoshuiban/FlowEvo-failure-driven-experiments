# Protocol A · 真实机制 Pilot

状态为设计完成，待冻结，尚未授权。计划使用 24 道有官方身份记录的数学题，按固定顺序分为三个八题窗口。题目选择、后续观察机会及候选停止规则须在模型请求前锁定。历史 50 题和 200 题仅供工程背景参考。

四组使用同一题序、同一冻结模型和无 Gold 基础求解协议。G 使用原生流程，T 学习历史题面，F 学习合法历史失败，R 依据上一完成窗口的 F 实耗辅助调用数获得额外求解额度。R 不读取失败内容或成绩。报告调用、Token 和费用各自的差异。T/F 比较针对完整工作流。

主要指标依次为独立来源失败关联、可交付候选、独立评审完成、Gate 通过、Shadow 执行、有限授权、后续不同原题介入。正确率和逐题胜负仅作描述。F 候选要进入机制证据统计，须能追溯到至少两个不同官方原题且谱系独立的失败。记录分母、无覆盖和未触达环节。

默认使用 AUTOMATED_GATE。由宿主在运行前冻结官方题面、独立参考答案、题目来源与曝光记录，并按可验证的语义契约冻结适用性标签和参数映射。测试池与在线题的原题和谱系隔离。生成模型不提供标签、参数参考或正确性证据。现有 Worker 执行候选，宿主以精确有理数比较器验证数学结果，并按池序选取前两个支持及前两个不支持案例。覆盖不足、没有冻结映射或无法可靠判定时，候选保留 Shadow。每组每个池至多启动一个候选版本的验证，失败或中断后不换版本试探同一池。签名盲审仍可显式选择。 [自动 Gate 配置](AUTOMATED_GATE.md)

启用现有 SOURCE、独立 Gate、Shadow 及有限授权约束。G/T/F/R 的共同题目、分组和配对统计规则固定。实际介入的独立收益依赖可验证谱系，正式介入后的同检查点原生反事实缺失时标记不可评价。Shadow 配对另报。

冻结清单包括干净源码 Commit 和逐文件 SHA、Worker 镜像及版本、任务顺序、原题和谱系清单、私有评分与 Gate 池 SHA、自动验证配置及其独立参考材料、真实模型及版本、供应商报价快照、各通道请求与 Token 限额、Worker 调用和时间上限、金额上限、主分析协议和脚本 SHA。设计上限为 192 个基础请求，T/F 每组每窗 48 个辅助请求，R 额外最多 96 个请求，合计最多 576 个。每请求最多预留 73,728 Token，共 42,467,328 Token。冻结时按实际供应商报价检查运行器的单位预留足够覆盖最坏成本，按通道核对总预算。报价与金额当前待绑定。

使用现有 `scripts/run_math_cumulative.py prepare` 绑定任务、谱系、私有评分及 Gate 池，并用 `--analysis-protocol` 绑定分析协议和脚本，再执行 `preflight`。两步均为零 API。模型发送须另行获得绑定完整计划哈希及预算的授权。UNKNOWN、未决外部副作用、账本异常、哈希漂移、泄漏、Worker 异常及硬预算耗尽须停止。自动模式沿用冻结检查点与账本恢复。禁止自动重发 UNKNOWN。

转入 B 的事前门槛为 F 至少两个来自不同失败簇且通过真实独立 Gate 的完整候选版本，并在至少三个不同官方原题、两个独立谱系上有实际介入及已确认终局评分。要求自动验证收据及数据来源可审计，且无未解决的泄漏或账本事件。该门槛用于确认机制触达。

## 50 题修订

以新版固定随机种子顺序执行 50 道 MATH-Hard Level 5 题，窗口为 1–20、21–40、41–50。此前的 24 题窗口和预算数字不适用于本修订。新版只冻结题单、顺序与私有评分绑定。数据集行身份可核验，原竞赛谱系及全量曝光待审。普通逐题分数可直接与标准答案比对。对算子的发布验证还须核验适用条件、参数映射和独立题上的表现。完整运行计划待绑定。

## 50 题学习诊断模式

当前 50 道 MATH-Hard 可用 LEARNING_DIAGNOSTIC 运行。此模式冻结数据集行身份、题序、私有评分和预算，保留学习及候选来源诊断，正式答案关闭算子介入。独立泛化继续使用 INDEPENDENT_GENERALIZATION 和原有独立 Gate 条件。参见 [诊断预检报告](../../reports/pilot50_learning_diagnostic_20261105/Report.md)。
