# Protocol B · 正式独立泛化实验

状态为独立方案，待 Protocol A 机制门槛达成后冻结。B 使用独立新题、新 Gate、新运行目录及预先注册的题序。冻结前验证这些题的官方身份、谱系和曝光清单，与 A、历史 50/200 题、生成来源和 Gate 曝光隔离。四组使用相同基础求解协议及题序，候选仍须满足完整版本绑定、独立验证、Gate、Shadow 和有限授权规则。

主比较是共同确认任务上 F–G 的官方原题等权正确率差。F–T、F–R 固定列为次要比较。报告全部配对胜负、退化、独立介入、各通道成本和缺失结果的全任务敏感性。原题变体先合并，按冻结谱系报告符号检验与效应区间。实际介入后的独立成功及 Shadow 原生配对分开报告。真实在线介入缺同检查点原生对照时，介入因果效果记为不可评价。

样本量规划以独立谱系和相互隔离的运行区块为单位。冻结前选定最小有意义效应 10 个百分点、双侧 alpha 0.05 和功效至少 80%。按配对不一致率 0.20、0.35、0.50 三个规划场景、10% 缺失以及预定区块和谱系结构模拟主分析功效。使用预先发布的模拟种子和选样规则，取所有可行情景达到目标的最小样本量。若预算不足或无法提供独立区块，重新标记为探索性方案。锁定最大样本量，禁止按中途成绩停止或延长。单一自适应流的区间和检验须按依赖性局限解释。

冻结完整分析协议、脚本 SHA、干净 Commit、数据和 Worker 清单、模型/版本、价格、按通道分列的调用与 Token 上限、Worker 上限、授权金额以及中止规则。沿用 Protocol A 的独立证据、零 API 预检和恢复控制。可选择可信自动验证或签名盲审，并使用独立冻结输入和新授权。最终样本数、报价、预算与真实评审身份仍待冻结。
