# ALFWorld 失败学习闭环

默认通过独立入口 scripts/run_alfworld_failure_learning.py 启用。

## 真实代码路径

1. 从冻结原生 Run 的 EPISODE_LOCKED、ACTION_RESPONSE 及哈希链导入可信失败。只接收 STEP_LIMIT、ACTION_CYCLE、NO_PROGRESS 且环境未完成目标的完整轨迹。交付截断和基础设施缺失不进入失败池。
2. 复用 FailureEvidenceStore 保存失败事实，保留全部公开轨迹。可发送视图确定性选取最多三条失败，每条保留前三步及末七步，并标记省略数量、原文摘要和文本片段。
3. 复用 BoundedCompiler 和 DeepSeek 持久化适配器，每次最多一次归纳和一次生成。模型可返回 NO_MECHANISM。机制、适用范围及 Python 策略均由模型提出；宿主不提供目标策略或旧模板源码。
4. 精确源码执行入口为 environment_operator(context)。返回一个合法环境动作与 JSON 状态，或明确拒绝。context 仅包含目标、公开观察、合法动作、当前任务公开历史和策略状态。代码经现有权限 lint 和实际 Docker Worker 执行，超时、只读文件系统、网络与资源限制沿用现有实现。
5. 源任务在相同求解配置下运行 G 与候选路径。候选需在源任务确实介入并成功；再在预冻结、与学习来源内容不重叠的 Gate 上运行同题 G/F 配对。
6. 原有 FailureOperatorRegistry 保存 Shadow、Gate 授权、有限机会、暂停与完成回执。环境策略新增独立 before_environment_step Hook 和 environment_action 能力，不共用代码修复动作契约。Gate 要求可靠性独有成功或至少两题模型调用节省，且没有可靠性回归及策略执行错误。
7. 获得权限后最多五个未来任务机会，运行时每步重新检查动作合法性。拒绝或冲突时调用原生生成器；策略输出错误触发暂停。来源任务和当前刚结束任务不会获得同题补救权限。
8. 未来任务 G/F 均结束锁定后，F 的新可信失败继续入库，触发下一次有界学习。G 的轨迹不进入 F 的生成请求。配对结果、实际策略动作、模型调用、Worker 时间和全部预算分别记录。

## 新 Pilot 草案

历史来源为上一轮 120 题中的 20 条完整失败。两个候选槽，每槽独享六道 Gate，另有六道未来任务，每类一道。Gate 来自 valid_seen，后续任务来自 train，均排除与历史及工程演练相同内容哈希的游戏。本研究角色为开发性跨游戏验证；不宣称新场景或严格独立泛化。

所有新 G/F 环境求解均用 DeepSeek Flash、温度 0、最多 50 步，动作输出上限固定 1024 Token。来源旧轨迹为 256 Token 协议，故源验证还运行同为 1024 Token 的新 G 对照，不能把交付额度变化归因于策略。

最大环境动作模型请求 2000 次，加归纳与生成 4 次。环境求解费用上限 29.60 美元，学习两份各 0.20 美元，总上限 30 美元；Worker 单列 2000 次与时间预算。费用预留采用每百万 Token 1.20 美元的保守上界。该新实验需要独立授权，旧 baseline 授权不适用。

## 验收与证据边界

工程验收使用固定 Mock 归纳和人工测试策略源码，在真实 ALFWorld 与 Docker Worker 上执行。Mock 工件无法进入真实运行。人工策略只存在于验收脚本，真实生成提示和生成结果不使用它。

源任务成功、Gate 通过、权限准入、后续调用与整题收益是不同状态。G/F Pilot 可以观察整体流程收益；失败证据相对 Task-Only 的独立贡献仍需要后续对照。

恢复只复用已结算模型响应与完成检查点。未完成 Worker、Gate 或环境 episode 保留待审状态，防止重复试探和重复消费权限。UNKNOWN 阻断新请求。环境状态中途丢失时需要审计恢复，当前入口不隐式重跑。

历史失败和部分新策略失败的根因可能不同；检索与症状共现均不构成共同机制证明。没有候选或验证不通过时，继续保留 Shadow，未来流程仍可使用原生求解。

实际配对退化会绑定具体已使用版本并暂停；相同源码再次生成只记录重复交付和成本，不重新赋予机会。所有工程数据均单独保存。发布前的“范围检查”是冻结环境样本上的经验检查，不能等同于对所有自然语言目标的形式证明。
