# ALFWorld 首轮基线实验

本轮研究当前 FlowEvo ALFWorld 原生动作链的任务成功率、失败类型和费用，使用现有 pure_dynamic 条件。它为后续失败学习实验提供可信轨迹。

官方文本环境为 ALFWorld 0.4.2 与 TextWorld 1.7.0。数据来自官方 release 0.2.2 的 JSON/PDDL 和 0.4.0 的 tw-pddl 游戏文件。官方 valid_unseen 中实际加载 134 个可运行任务。按六类各随机抽两题、种子 20261107 固定题序，共 12 题，每题单次尝试，最多 50 步。其余题不因基线表现重新挑选。 [官方环境和数据](https://github.com/alfworld/alfworld)

运行复用 AlfWorldEnv、AlfWorldGenerator、AlfWorldExecutor。模型只看到任务目标、当前观察、最近动作与观察、可执行命令。保持仓库现有 Think/Act 提示和动作解析器，包括原有的通用任务提示及解析回退。类别名、游戏文件路径、参考轨迹、expert plan、事实状态和私有目标条件均不进入模型请求。

统一使用 DeepSeek API 的 deepseek-flash，温度 0，输出上限 256 Token，关闭 thinking，输入保守上界 10,000 Token。沿用当前预发送连接恢复策略，最多三次建立连接，等待 2/5 秒；POST 后 UNKNOWN 保留预算并阻断，不自动重发。复用 SharedTransport、PersistentBudget 和 network_transport，不经过旧的自动请求重试客户端。恢复以冻结任务和动作请求哈希重放，同一请求结算后复用响应。冻结数据与源码变化则拒绝继续。

授权为本轮独立 8 美元。最多 600 次动作请求、6,153,600 Token。按每百万 Token 1.20 美元统一保守预留，冻结请求配置的理论预留至多 7.384320 美元。实际估算另按模型 usage 核算。预算占用、估算和供应商账单分开报告。 [官方价格](https://api-docs.deepseek.com/quick_start/pricing/)

任务成功只使用官方 won 信号。done 可能仅表示步数耗尽。分别报告成功、步数耗尽、动作循环、连续无进展、基础设施或交付缺失，逐题保存原始模型响应和环境反馈。主要指标为任务成功数/可评价任务数，另报告全部 12 题分母、各类型成功数、动作及模型请求数、Token、费用、环境时间和解析回退。

零 API 阶段使用冻结的 12 个真实游戏和固定 Mock look 动作。该验收只证明环境、动作链、账本和终止判定。真实阶段不编译或启用技能库。仓库原有编译器从成功轨迹和人工任务蓝图构建模板，后续如研究失败驱动学习，必须单独接入可信失败和自动生成来源，区分成功经验与失败学习贡献。

这 12 题作为开发 Pilot 曝光，单次运行只支持描述性判断。后续比较应冻结新的连续任务流，区分原生基线、Task-Only 与 Failure-Driven，保持同任务与基础预算，并记录学习和验证成本。
