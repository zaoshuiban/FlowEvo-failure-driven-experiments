# FlowEvo v4 技能迁移 Pilot 协议草案

状态 `ENGINEERING_PARTIAL`。真实 TRAIN 与 TEST 分别授权。

- TRAIN 固定 10 条真实可信失败。A 复用累计机制簇，B 每条失败提供一次单失败技能机会，C 保留可检索文本，D 以 B 的生成方式开始并在 DEV 上比较版本。R 不读取历史经验。
- DEV 固定 8 题。使用私有参考执行数学验证，绑定完整候选版本。仅通过现有安全、计算、路由、发布和有限授权路径的技能可进入后续任务。版本变化重新验证。
- TEST 固定 48 题。先锁定共同的两次原生求解，A/B/C/D/R 各从同一检查点获得一次后续求解调用。只有 C 可以注入文本卡片，A/B/D 可以注入经授权的技能执行结果。R 仅作普通追加计算。统一模型、输出上限和私有评分。当前原竞赛谱系未知，结论限于探索性迁移。
- 主要比较 B 对 C、D 对 B、B 对 A，以及各组对 R。统计按题配对，报告独有成功、退化、平局、缺失、净差和配对不确定性。分别保留原生和后续结果，按技能类型记录拒绝、介入和结果。没有合格 B/D 技能时，停止正式迁移阶段。
- 预算草案为 TRAIN 最多 100 次（A 40、B 20、C 10、D 30），DEV 56 次，TEST 336 次。按每次 73,728 Token 上界、历史每次最高 0.088474 美元口径，总计最多 492 次、36,274,176 Token、约 43.53 美元。真实启动前需重核价格，并将实际 Gate 与修订的调用纳入各通道硬限额。另列 Worker 时间和实际 API usage。
- 发生未知请求、数据污染、版本或预算不一致时停止。已完成请求依账本恢复。TEST 在库版本与适用性标注冻结后执行，结果不回流训练。
