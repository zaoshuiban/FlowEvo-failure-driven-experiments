# E1 / E2 实验报告

本实验审查历史程序，不重新估计 800 题的在线 FlowEvo 成功率。E1 发现新评分规则仍有缺陷；上轮 529/800 等数字不能直接解释为高可信算法成功率。

### 关键证据

- **18 道旧 PASS、新 WA 全部发现评测问题**：11 道参考输出数量不符，5 道参考结果错误或错序，1 道查询数量契约违例，1 道 int/float 数值类型强制一致误判。不能把这 18 道解释为模型算法退化。
- 原 TACO 比较器会将输出行及行内 token 转为集合，丢失顺序和重复次数。它能掩盖错误参考；新规则改成有序比较后，这些坏参考反而会拒绝正确程序。源代码位置：历史 TACO testing_util.py 第 456–488 行。
- **taco_0617 的新语义检查器绑定错题**：题面是关系图组队，检查器却要求能力值 1/2/3。这是上轮修复引入的真实问题。
- **taco_0291 的修复退化**：l3 程序通过本轮独立核验的 93 组合法隐藏测试；后续 l4 用满 32768 输出 Token，代码块未闭合，最终程序无法编译。这只证明本轮测试上的退化，不证明 l3 全域正确。
- **taco_0604 的参考错误**：A:x→−x、B:x→2−x 都是对合；非交叉完全配对必须复合为恒等映射。十个词均把 0 映射到非零，故正确计数为 0，参考 1 错误。独立证明保存在该题证据目录。

### 未知的两题

- `lcb_atcoder_abc371_f`：合法大输入下超时，但未完成资源匹配的高效 Python 参考实现对照，不能确证是候选效率缺陷还是时间阈值问题。
- `taco_0857`：旧首例超时、本次通过；不能用后续非法输入解释首例超时，环境差异尚未排除。

### 审查与复现

93 题均保存原始最终程序、题面、历史候选与旧反馈、新沙箱重放、输入/参考契约证据和复现命令。原始程序哈希与冻结清单核对一致。对评测问题，保留的是具体非法输入或错误参考证据，不伪造合法算法反例。

E1 无新增生成 API 调用。独立公开测试覆盖 22 个任务的历史候选，使用 minimax、排列穷举、森林穷举、生成树枚举、直接模拟、精确分数等方法；小测试通过不构成全域正确证明。

## E2：代码完整性失败的辅助试验

**原研究主问题尚无合格算法失败样本，不能据本轮回答“纠正错误类别是否提高算法恢复率”。** 本轮实际入选 taco_0291 和 lcb_atcoder_abc399_e 两个截断代码检查点，最多 12 次调用。R0 宽泛类别本来就包含编译错误，R1 将类别收窄，R2 增加题面独立生成的公开输入、可计算答案和公开编译观察；不存在隐藏反例泄露。

R0 是从历史最终失败程序继续一次修复，固定历史模板、题意、技能上下文和模型参数，不声称完整重放原请求。该执行调整在第一次 API 调用前写入 [补充协议](E2执行补充协议.md)。完全相同反馈的负对照队列为 0；真正算法失败上的错误反馈纠正主队列为 0。

三臂使用相同冻结隐藏评分规则。LCB 44 组测试均通过输入及独立图 oracle 的参考核验；TACO 240 组中保留 93 组，147 组因契约违例或奇数页物理解释歧义被隔离（不代表147组均已确证非法）。保留测试参考值无须更改。oracle 先通过 819 对小字符串的 BFS 穷举核验和 42 组物理书页子集期望核验。

执行状态：`COMPLETED`；已发起 12 次调用；API 已报告 218,445 个总 Token；含未知费用请求预留的保守预算占用 218,445。Token 上限 3,000,000，调用上限 72。

|反馈|已评分修复数|审计隐藏测试 PASS|恢复率|原v2规则PASS|总Token|
|---|---:|---:|---:|---:|---:|
|R0|4|2|50.0%|0|75,935|
|R1|4|2|50.0%|0|75,062|
|R2|4|4|100.0%|2|67,448|

该恢复率只针对两道代码完整性任务，每臂每题重复两次；独立任务数是 2，不能把 4 次调用当成 4 道独立题。小样本与辅助队列性质决定本轮不能支持显著性或一般因果结论。推理 Token 已包含在 completion/total 中，不能再次相加。无已核实单价，因此不编造货币金额。

请求模型标识为 `deepseek-reasoner`，12 次实际返回模型均为 `deepseek-flash`，与历史实际返回模型一致。本轮没有模型变化或传输重试。

E1 公开验证覆盖 22 道题、110 个历史候选，生成 763 个输入批次，执行 3,649 次沙箱测试：105 个候选通过了这些公开测试，4 个为空代码，1 个编译失败。小规模测试通过不证明全域正确。

本次根因审查由助手结合题面、代码和执行证据完成。“独立证据”指不同实现的 oracle、穷举或数学不变量，不表示已进行双人盲审。E1 没有向被评测生成模型发起额外调用。
