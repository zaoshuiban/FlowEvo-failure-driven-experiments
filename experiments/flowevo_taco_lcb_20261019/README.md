## 评测口径

TACO 使用官方 test 集，每个难度 200 题中抽取 100 题。LiveCodeBench 固定 code_generation_lite release_v6，easy/medium/hard 各抽 100 题。抽样种子 20261019，以 SHA256 排序确定样本及运行顺序。

使用 FlowEvo 官方 code_math ours 适配实现，提交 36e81efd4d1fdbabca7366200b15808ebef157fa；各数据集、难度拥有独立的在线技能库。每题最多 5 次尝试，包括初始生成、替代候选和反馈修复；最终通过率使用全部测试的反馈，不是隐藏测试无反馈的 pass@1。首次候选通过率单列。适配还修改了任务提示、修复上下文长度和输出预算，因此应标为 FlowEvo 适配实验。

请求模型 deepseek-reasoner，实际返回模型为 deepseek-flash；开启 thinking，reasoning_effort=high，每次 max_tokens=32768。共 2132 次 API 调用、28,421,557 tokens。

TACO 每测试用例超时 4 秒，LCB 为 6 秒。按官方测试器接受情况判定；已有参考解自检显示部分 TACO 参考解也未获通过，因此这些分数代表该测试器下的接受率，尚未对该现象做独立归因或修正。
