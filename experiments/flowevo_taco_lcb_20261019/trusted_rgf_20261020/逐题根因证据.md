## lcb_atcoder_abc301_f

分类：VERIFIED_ALGORITHM_FAILURE（实现缺陷；不代表算法选择错误）。

输入为长度4的字母串 AaAA；不存在符合DDoS条件的四位置子序列，唯一填充方案合法，结果1。

根因：A combinatorial table is sized using the length of the current input, but later indices also range over a fixed alphabet of 26 symbols. Legal short inputs can therefore request an unallocated index. Allocate for every reachable index, not just the input-length variable.

最小修复：
```diff
--- historical_l1.py
+++ counterfactual.py
@@ -29,6 +29,7 @@
     all_lower = lw_after
     ans = (all_lower + H[0]) % MOD
 
+    n = max(n, 26)  # factorial indices include the entire alphabet
     fact = [1] * (n + 1)
     pow26 = [1] * (n + 1)
```

## taco_0875

分类：VERIFIED_ALGORITHM_FAILURE（实现缺陷；不代表算法选择错误）。

n=1100，父节点依次为2至1100、末节点为-1，所有父节点合法且无环。整条链任意两人有祖先关系，至少1100组；每人单独成组可行，故答案1100。

根因：Memoization reduces repeated work but does not reduce the maximum depth of recursive calls. A legal deep chain can exceed the language runtime recursion limit before producing an answer. Distinguish graph cycles from a long acyclic chain.

最小修复：
```diff
--- historical_l1.py
+++ counterfactual.py
@@ -1,4 +1,5 @@
 import sys
+sys.setrecursionlimit(10000)
 
 def main():
     data = list(map(int, sys.stdin.buffer.read().split()))
```
